Рекомендательная система для e-commerce: предсказывает вероятность покупки пары «пользователь–товар» и возвращает top-K рекомендаций. Включает Jupyter-ноутбук со сравнением трёх подходов (коллаборативная фильтрация, факторизационные машины, XGBoost) и FastAPI-сервис с in-memory кешем. Лучший результат показали факторизационные машины (AUC 0.996, F1 0.92) — они сохранены как основная модель.

Запуск: python app_cashing.py (модель best_model_fm.pkl рядом со скриптом, порт по умолчанию 8001, Swagger — /docs). Эндпоинты: /recommend/user-to-items, /recommend/item-to-users, /score/{visitorid}/{item_id}, /rating/global + метрики кеша в /cache/stats.
